# Noti HDD

`Noti HDD`는 디스크 활동을 감지해 LED 스타일 상태 아이콘으로 표시하는 macOS 메뉴바 앱입니다. 이 앱에는 햄스터 애니메이션, 이동 방식 제어, 크기/속도 설정, 원형 마우스 동작 또는 흔들기 기반 일시정지 기능을 포함한 눈운동 오버레이도 함께 들어 있습니다.

## 주요 기능

- 디스크 활동을 표시하는 메뉴바 LED 인디케이터
- 선택 가능한 알림 LED 색상 스타일
- 그림 또는 사진 햄스터 스타일을 지원하는 눈운동 오버레이
- 간격, 속도, 크기, 이동 모드 조절
- 원형 동작 또는 마우스 흔들기로 오버레이 일시정지

## 프로젝트 구성

- `Noti HDD.xcodeproj`
- `Noti HDD`
- `buildrun.sh`
- `launch.sh`
- `backup.sh`

## 빌드 및 실행

`Release`로 빌드한 뒤, 앱을 프로젝트 루트에 복사하고 바로 실행합니다.

```bash
./buildrun.sh
```

나중에 복사된 앱만 다시 실행하려면:

```bash
./launch.sh
```

복사된 앱 번들은 아래 경로에 생성됩니다.

```text
./Noti HDD.app
```

## 참고 사항

- 메인 앱 타깃과 스킴 이름은 `Noti HDD`입니다.
- 디버그 로그는 가능하면 앱 근처 또는 현재 작업 디렉터리의 쓰기 가능한 `debug.log` 위치에 기록됩니다.
- 소스 백업 zip은 `./backup.sh`로 만들 수 있습니다.
