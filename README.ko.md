# Noti HDD

`Noti HDD`는 디스크 활동을 감지해 LED 스타일 상태 아이콘으로 표시하는 macOS 메뉴바 앱입니다. 이 앱에는 나로호 형태의 작은 로켓 애니메이션, 이동 방식 제어, 크기/속도 설정, 원형 마우스 동작 또는 흔들기 기반 일시정지 기능을 포함한 눈운동 오버레이도 함께 들어 있습니다.

## 주요 기능

- 디스크 활동을 표시하는 메뉴바 LED 인디케이터
- 선택 가능한 알림 LED 색상 스타일
- 메뉴의 나로호 로켓 미리보기와 로켓이 움직이는 눈운동 오버레이
- 간격, 속도, 로켓 크기(10~100%, 기본 50pt), 이동 모드 조절
- 이동 속도 슬라이더와 숫자 입력의 동기화, 설정 저장
- 원형 동작 또는 마우스 흔들기로 오버레이 일시정지

## 눈운동 이동 속도

기본 속도는 **3단계**로, 화면의 긴 방향을 한 번 이동하는 데 약 **6초**가 걸립니다. 각 구간의 이동 시간은 거리에 비례해 계산하며, 최소 0.1초입니다. 목표점에서 1초 쉬고 다음 구간을 이동합니다.

메뉴의 이동 속도 슬라이더, 숫자 입력, 스테퍼로 1~10단계를 조정할 수 있습니다. 1단계에서는 긴 방향 이동에 약 18초, 10단계에서는 약 0.1초가 걸립니다. 빠른 구간인 7~10단계는 각각 0.8초, 0.4초, 0.2초, 0.1초입니다. 변경한 설정은 저장되며 다음 이동 구간부터 적용됩니다. 이전 속도 계산을 쓰던 설정은 새 기본값으로 시작합니다.

[CHOP의 눈 추적 운동 안내](https://chopib.staywellsolutionsonline.com/Library/Encyclopedia/22%2C36023)는 한쪽 방향으로 약 3초부터 시작하도록 안내하며, [Mersey Care NHS의 안내](https://www.merseycare.nhs.uk/patient-leaflets/balance-and-gait)는 목표를 천천히 추적하도록 설명합니다. 이를 참고해 6초를 앱의 시작값으로 정했습니다. 실제 눈의 회전 속도는 화면 크기와 보는 거리에 따라 달라지며, 이 값은 임상적으로 검증된 최적 속도가 아닙니다.

## 프로젝트 구성

- `Noti HDD.xcodeproj`
- `Noti HDD`
- `buildrun.sh`
- `launch.sh`
- `backup.sh`

## 빌드 및 실행

macOS 13 이상과 Xcode가 필요합니다.

`Release`로 빌드한 뒤, 앱을 프로젝트 루트에 복사하고 바로 실행합니다.

```bash
./buildrun.sh
```

나중에 복사된 앱만 다시 실행하려면:

```bash
./launch.sh
```

복사된 앱 번들은 아래 경로에 생성됩니다.

```text
./Noti HDD.app
```

## 참고 사항

- 메인 앱 타깃과 스킴 이름은 `Noti HDD`입니다.
- 디버그 로그는 현재 콘솔에 출력되며 파일 기록은 비활성화되어 있습니다.
- 소스 백업 zip은 `./backup.sh`로 만들 수 있습니다.
